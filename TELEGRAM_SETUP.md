# 📲 Как добавить «Крушителей» в Telegram (Mini App)

Игра — это один файл `krushiteli-prototype/index.html` (~90 КБ, без зависимостей).
Telegram открывает её внутри мессенджера как **Telegram Mini App** — по кнопке
у бота или в меню чата. Подключение занимает ~10 минут.

---

## Шаг 1. Хостинг (обязателен HTTPS)

Telegram открывает Mini App только по адресу `https://`. Локальные файлы (`file://`)
он открывать отказывается. Самые простые бесплатные варианты:

### Вариант А — GitHub Pages (бесплатно, навсегда)
1. Зарегистрируйся на github.com (если аккаунта нет).
2. Создай репозиторий: кнопка **New repository**, имя например `krushiteli`,
   видимость **Public**.
3. В репозитории: **Add file → Upload files** → перетащи `index.html` → **Commit changes**.
4. Открой **Settings → Pages**, в поле Branch выбери `main` (root) → **Save**.
5. Через 1–2 минуты игра доступна по адресу
   `https://ТВОЙ_НИК.github.io/krushiteli/` — проверь в браузере, что открылась.

### Вариант Б — Netlify Drop (быстрый тест, меньше движений)
1. Открой **app.netlify.com/drop**.
2. Перетащи папку `krushiteli-prototype` прямо на страницу.
3. Получишь адрес вида `https://что-то.netlify.app` — готово.

> Локальный тест через туннель (localtunnel/cloudflared) требует установленного
> Node.js — на этой машине его нет, поэтому без особой нужды пропускаем.

---

## Шаг 2. Бот в @BotFather (~3 минуты)

1. Открой в Telegram бота **@BotFather** → команда `/newbot`.
2. Имя бота: например `Крушители: Клановые Войны`.
   Username: обязан заканчиваться на `bot`, например `krushiteli_bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA…` — это ключ управления ботом.
   **Никому не показывай** (можешь прислать сюда мне — я сам привяжу игру, см. Шаг 3).
4. Привяжи игру к боту, всё в том же @BotFather:
   - команда `/newapp` → выбери своего бота → иконка (можно скипнуть) →
     короткое имя (`krushiteli`) → описание (по желанию) → и в конце
     поле **Web App URL**, куда вставляешь адрес из Шага 1.
   - После этого у бота появится **кнопка запуска Mini App** — игра откроется на
     весь экран прямо в чате.

   Альтернатива: `/setmenubutton` → выбери бота → отправь URL игры.
   Это добавит кнопку «меню» у поля ввода сообщений в чате с ботом.

## Шаг 3. Автопривязка (можно поручить мне)

Пришли мне сюда **токен бота** + адрес хостинга — я сделаю привязку сам через
Bot API (`setChatMenuButton` / `setMenuButton`), BotFather не понадобится.

⚠️ Токен = пароль бота, поэтому:
- после подключения его можно отозвать командой `/revoke` в BotFather
  (привязка игр сохранится, старый токен перестанет работать);
- никогда не публикуй токен в коде, комментариях и скриншотах.

То же самое руками, без меня (адрес вставить свой):

```
https://api.telegram.org/bot<ТОКЕН>/setChatMenuButton?menu_button={"text":"⛏ ИГРАТЬ","web_app":{"url":"<АДРЕС_ИГРЫ>"}}
```

## Что игра умеет уже сейчас внутри Telegram

| Функция | Как работает |
|---|---|
| 📱 Полноэкранный режим | игра раскрывается на весь экран (`expand()`), тёмная тема зашита в HUD |
| 🫳 Хаптика | вибро-отклик на тапы, Контрошу, покупки, победы/провалы (iOS/Android) |
| ☁️ Облачный сейв | `Telegram.WebApp.CloudStorage` — прогресс едет между телефоном и ПК |
| 👤 Дед узнаёт игрока | подхватывает имя профиля Telegram и здоровается лично |
| 🚫 Без случайного выхода | вертикальные свайпы отключены — свайп не закрывает игру |
| 🔊 Звук | включается первым тапом (политика автоплея), в Telegram работает как есть |

Если сейв есть и в облаке, и локально — берётся более свежая копия (по метке `lastSeen`).

## Чек-лист после первого запуска в Telegram

1. Открыть с телефона: тапы бьют, вибро шевелится, звук играет.
2. Пройти пару этажей → закрыть чат → вернуться: прогресс на месте.
3. Открыть на втором устройстве: прогресс подтянулся из облака.
4. Порепетировать престиж (эт. 20+) и рейды (эт. 3+) — ничего не вылетает.

## Возможные вопросы

- **Бот-профили:** чью ссылку я даю друзьям? Ссылку на бота `t.me/имя_бота` —
  оттуда игра запускается кнопкой.
- **Хочу выделенный канал клана?** Позже можно сделать второго бота-клановщика
  и вшить приглашения прямо из игры (клановая система из GDD).
